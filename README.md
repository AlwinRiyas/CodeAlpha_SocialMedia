# CodeAlpha Social Media Platform

A full-stack social media platform developed as **Project 2** of the CodeAlpha Full Stack Development internship.

## Project scope

The application will provide:

- User registration and authentication
- User profiles
- Posts and feed
- Comments
- Likes
- Follow and unfollow relationships
- Notifications
- Responsive web interface

The required CodeAlpha task is to build a mini social media application with user profiles, posts and comments, a like/follow system, and a database covering users, posts, comments, and followers.

## Technology stack

### Frontend

- React
- Vite
- React Router

### Backend

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT authentication

### Development

- GitHub
- Git feature branches and pull requests
- VS Code

## Development workflow

`main` is the stable branch. Features are developed in dedicated branches, tested locally, pushed to GitHub, and merged through pull requests.

```text
feature branch → local development → testing → commit → push → PR → merge → main
```
